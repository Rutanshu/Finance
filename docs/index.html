Click any arrow on the map and it opens down to exactly which tab and column fed which — not just which file.

Auto-detected links

Every cross-file formula and external-link table becomes an arrow, read straight out of the workbook.

External source detection

Database connections, web queries, and live WEBSERVICE() formulas are flagged and traced to the exact tab they load into — credentials redacted before display.

Radial tabs view

Select a workbook to see every tab and what connects to each one as a hub-and-spoke diagram.

Big-screen flow view

Expand any workbook into a full Sources → Tabs → Columns → Destinations flow on the main canvas.

Declared handoffs

Record the copy-pastes, emails and re-keying no scanner can see — usually your highest-risk hops.

Runs entirely offline

Binds to 127.0.0.1 only. No HTTP client is imported anywhere in the package — check the source yourself.
